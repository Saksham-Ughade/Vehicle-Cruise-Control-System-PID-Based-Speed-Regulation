# Vehicle-Cruise-Control-System-PID-Based-Speed-Regulation
Modelled a vehicle cruise control system in MATLAB/Simulink with PID control, simulating throttle dynamics, drag forces, and road disturbances. Achieved &lt;5% overshoot with full disturbance rejection. Generated embedded C code via Simulink Embedded Coder demonstrating automotive Model-Based Design (MBD) workflow
